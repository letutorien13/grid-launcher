# 🇫🇷 Grid Launcher (`grid-launcher@letutorien`)

## Description

**Grid Launcher** est un applet innovant et ultra-compact conçu spécifiquement pour l'environnement de bureau Cinnamon. Il permet de regrouper plusieurs lanceurs d'applications au sein d'une seule et unique case de votre tableau de bord, sous la forme d'une mini-grille visuelle de 2x2 icônes.

### Pourquoi avoir créé cet applet ?

Les lanceurs traditionnels de Cinnamon s'alignent horizontalement ou verticalement, occupant rapidement un espace précieux sur le tableau de bord. Dès que l'on souhaite épingler de nombreuses applications, la barre des tâches devient encombrée et perd en lisibilité. **Grid Launcher** est né de la nécessité de centraliser et d'organiser ses logiciels par catégories thématiques (ex: Bureautique, Jeux, Développement) sans saturer l'écran.

### Intérêt pratique & Ergonomie

* **Gain de place massif :** Logez jusqu'à 4 applications (et plus dans le menu) dans l'espace d'une seule icône standard du panel.
* **Lisibilité accrue :** Identifiez instantanément le groupe d'applications grâce à l'aperçu dynamique en mini-grille et aux infobulles personnalisables.
* **Multi-instances :** Installez et ajoutez autant de grilles que nécessaire sur vos différents panneaux.
* **Gestion intuitive :** Glissez-déposez vos applications directement depuis le menu principal pour les ajouter, et renommez vos catégories à la volée via Zenity.

---

## Installation

### 1. Cloner ou copier les fichiers

Créez un dossier nommé `grid-launcher@letutorien` dans votre répertoire d'applets local :

```bash
mkdir -p ~/.local/share/cinnamon/applets/grid-launcher@letutorien

```

Placez-y les fichiers `applet.js` et `metadata.json`.

### 2. Activer l'applet

* Faites un clic droit sur votre tableau de bord Cinnamon et sélectionnez **"Ajouter des applets au tableau de bord"**.
* Recherchez **Grid Launcher**.
* Cliquez sur le bouton **"+"** pour l'ajouter à l'emplacement de votre choix.

# 🇬🇧 / 🇮🇪 English

## Description

**Grid Launcher** is an innovative, ultra-compact applet built specifically for the Cinnamon desktop environment. It allows you to group multiple application launchers into a single panel slot, displayed as a visual 2x2 mini-icon grid.

### Why this applet was created

Traditional Cinnamon launchers line up horizontally or vertically, quickly consuming valuable panel space. **Grid Launcher** resolves this layout stress by grouping software into thematic categories (e.g., Office, Dev, Gaming) without cluttering your workspace.

### Practical Benefits & Ergonomics

* **Massive Space Saving:** Fit multiple apps into the space of one standard panel icon.
* **Visual Overview:** Instantly identify groups via the dynamic 2x2 preview grid and custom tooltips.
* **Multi-Instance Support:** Deploy as many grid categories as you want across your panels.

## Installation

1. Create the local directory:
```bash
mkdir -p ~/.local/share/cinnamon/applets/grid-launcher@letutorien

```


2. Drop `applet.js` and `metadata.json` inside.
3. Right-click your Cinnamon panel -> **"Add applets to the panel"** -> Select and add **Grid Launcher**.
